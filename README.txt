Momentea 웹앱 프로토타입 (iPhone 13 · 390×844 고정)

■ 여는 방법
  압축을 풀고 index.html 을 더블클릭하면 됩니다. (Chrome · Safari · Edge 권장)
  인터넷 연결이나 서버 없이 동작하며, 폰트·아이콘·이미지가 모두 폴더 안에 들어 있습니다.
  PC에서는 기기 프레임 안에 표시되고 창 크기에 맞춰 축소되며, 휴대폰에서 열면 화면에 꽉 차게 표시됩니다.

■ 전시용 (자세한 순서는 함께 전달한 '모먼티 전시 설치 안내' 문서 참고)
  · 이 폴더를 웹에 올리면(예: GitHub Pages) 아래 주소로 쓸 수 있습니다.
      주소/                 자유 체험 (아이폰에서 '홈 화면에 추가'하면 앱처럼 전체 화면 + 오프라인 실행)
      주소/?flow=pansy      QR 체험: 보나플로 팬지꽃차 — 사진 검색 → 차 정보 → 타이머 → 후기 → 체험 완료
      주소/?flow=hibiscus   QR 체험: 데이오브힙 모닝힙 블렌드(히비스커스) — 같은 흐름
      주소/qr.html          위 세 주소의 QR 코드를 만들고 인쇄/SVG 저장
  · 홈 화면에 추가한 앱은 2분 동안 아무도 만지지 않으면 처음 화면으로 돌아갑니다.
  · sw.js 가 모든 파일을 저장해 두어 처음 한 번 연 뒤에는 인터넷 없이 동작합니다(파일을 고치면 sw.js 도 함께 다시 올리기).

■ 화면 흐름
  온보딩 → 홈(최근 기록 / 현재 인기 / 취향 추천)
    ├ 하단 탭 바 가운데 + 버튼 → 사진 검색 · 음성 검색 · 키보드 검색 버튼이 펼쳐짐
    ├ 검색 탭/검색창 → 자동 타이핑 시연('홍차' 입력 → 홍차 제품 추천 11종) → 검색 결과(홍차 12종) → 제품 상세
    ├ 마이크 → 음성 검색(마이크 버튼을 누르면 인식 시연) → 검색 결과
    ├ 카메라 → 사진 검색(셔터를 누르면 인식 시연) → 제품 상세
    ├ 카드·배너·순위 → 제품 상세
    ├ 하단 탭 바 얼굴 아이콘 → 마이페이지(이번 주 기록, 좋아하는 차로 바로 우리기)
    └ 하단 탭 바 톱니바퀴 → 설정
  제품 상세 → 우리기 설정 → 3·2·1 카운트다운 → 타이머(펼치기/접기, 일시정지, 정지)
    → 완료 알림(한 번 더 마시기 / 다 마셨어요) → 후기 기록 → 마이페이지(이번 주에 즐긴 차 카드에 오늘 도장)

■ 파일 구성
  index.html        화면 구조
  style.css         스타일·모션
  js/app.js         화면 전환·인터랙션
  js/data.js        제품·문구 데이터
  js/detail-data.js 제품별 상세(원재료·우리는 법·맛·후기 요약·후기 7개·구매처) 데이터
  js/hangul.min.js  한글 조합(hangul-js, MIT)
  assets/           폰트(Pretendard·Archivo Black, OFL), 아이콘, 사진, 차종별 우려내기 영상(video/*.mp4)

■ 참고
  · Mac/iPhone에서는 시안과 같은 Apple SD Gothic Neo로, 그 외 기기에서는 내장된 Pretendard로 표시됩니다.
  · 3·2·1 카운트다운 동안은 조용하고, 타이머가 시작되는 순간부터 바흐 「전주곡 C장조 BWV 846」 피아노 연주가 배경음악으로 흐릅니다.
    ('한 번 더 마시기'를 누르면 카운트다운 동안 멈췄다가 다음 타이머에서 이어서 재생)
    (퍼블릭 도메인 곡을 Salamander Grand Piano 샘플(CC BY 3.0, Alexander Holm)로 렌더링)
  · 타이머 배경은 차종별 우려내기 영상(각 약 30초)입니다.
    팬지꽃차 → 팬지꽃, 캐모마일 → 캐모마일, 말차 → 녹차, 홍차·블렌딩 홍차·후발효차 → 홍차(보이차), 데이오브힙 모닝힙 블렌드 → 히비스커스.
    맞는 영상이 없는 차(뽕잎·연잎·채소·상황버섯·돼지감자·연근)는 색이 비슷한 영상으로 진행하고 카운트다운 위에 안내 문구가 뜹니다.
  · 타이머는 영상에 맞춰 흐르고, 영상 종료 3초 전에 완료 알림이 뜹니다.
    알림이 뜨고 4초 뒤 '이제 다 마셨어요'가 자동으로 눌려 후기 기록으로 넘어갑니다.
  · 제품 상세의 원재료·우리는 법·맛 표현·후기는 공식 판매 페이지와 실제 구매 후기를 참고해 문장을 다듬은 것이고,
    평점·평가 수·응답 비율(%)은 시연용 값입니다. 후기 프로필 사진은 동물 사진 8장(assets/img/pet1~8) 중에서 배정됩니다.
  · 제품 상세 상단 사진과 후기 기록 화면의 사진·배경색은 Figma '클로드 확인용' 시안(15종)의 크롭과 색을 그대로 옮겼습니다(assets/img/d_*, r_*).
  · 타이머 팁 문구는 배경 영상 차종(팬지꽃·히비스커스·홍차/보이차·녹차·캐모마일)별 5개 중에서 섞여 나옵니다.
    영상이 없는 차는 타이머 화면의 차 이름·팁도 영상 차종을 따르고, 후기 기록에서는 실제 제품으로 표시됩니다.
